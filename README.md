# icloud-mcp

Личный MCP-сервер для одного ящика iCloud. Даёт Claude поиск, чтение, отправку, драфты, раскладку писем и отписку от рассылок. Живёт на Vercel, базы данных нет.

## Настройки (Environment Variables в Vercel)

| Переменная | Что это |
| - | - |
| `ICLOUD_EMAIL` | адрес ящика, например `name@icloud.com` |
| `ICLOUD_APP_PASSWORD` | app-specific пароль от Apple (account.apple.com, Sign-In and Security, App-Specific Passwords) |
| `OWNER_PASSPHRASE` | пароль владельца, от 12 символов. Его вводишь на странице входа, когда подключаешь коннектор |
| `FROM_NAME` | необязательно: имя отправителя в письмах |

После изменения переменных нужен Redeploy.

## Подключение в Claude

Кастомный коннектор с адресом `https://<проект>.vercel.app/mcp`. Claude откроет страницу входа сервера, там вводится `OWNER_PASSPHRASE`.

## Инструменты

- `list_folders`: папки, роли, счётчики
- `search_emails`: поиск по папке (текст, отправитель, тема, даты, непрочитанные)
- `read_email`: письмо целиком текстом, вложения списком, доступные способы отписки
- `send_email`: новое письмо или ответ, копия ложится в Sent
- `create_draft`: то же, но в Drafts без отправки
- `update_emails`: прочитано, флаг, архив, корзина, спам, перенос
- `list_subscriptions`: отправители рассылок в последних письмах
- `unsubscribe`: отписка по письму. Порядок: one-click POST (RFC 8058), письмо на mailto из заголовка, ссылка из заголовка, ссылка из тела

## Как закрыт доступ

- Без токена `/mcp` отвечает 401. Токен выдаётся только после ввода `OWNER_PASSPHRASE`.
- Код входа уходит только на `https://claude.ai/api/mcp/auth_callback` или на localhost (так подключается Claude Code). Любой другой адрес возврата отклоняется.
- PKCE S256 обязателен.
- Токены подписаны ключом, который выводится из `OWNER_PASSPHRASE` и `ICLOUD_APP_PASSWORD`. Смена любого из них и Redeploy отзывает все выданные токены разом.
- Сервер без базы, поэтому два ограничения: код входа живёт 2 минуты и защищён PKCE, но не одноразовый; при обновлении токена старый refresh-токен доживает свой срок (90 дней). Отзыв делается сменой `OWNER_PASSPHRASE`.
- Неверный пароль на странице входа отвечает с задержкой 1.5 секунды. Перебор сдерживает длина пароля, поэтому короче 12 символов сервер не принимает.
- Ссылки отписки берутся из писем, то есть из чужого текста. Сервер ходит только по http/https, проверяет каждый редирект и не обращается к локальным и приватным адресам.
- Удаления навсегда нет: `trash` переносит в корзину.

## Проверка

`npm test` поднимает в одном процессе строгий тестовый IMAP-сервер (hoodiecrow), SMTP-приёмник и фальшивый сайт рассылки, проходит настоящий OAuth-флоу и вызывает все инструменты официальным MCP-клиентом, в том числе через эмуляцию маршрутизации Vercel.

Чего этот прогон не показывает: поведение самого iCloud (логин, имена папок, поиск по кириллице) и деплой на Vercel. Тестовый IMAP-сервер сравнивает заголовки побайтно, поэтому поиск по не-ASCII на нём не проверяется.
